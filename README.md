# Tech Samachar

Technology, filtered for you.

A personalized, AI-powered technology news platform for personal use. It automatically collects technology news from reliable sources, organizes it by topic, summarizes it using AI, and prioritizes articles according to interests.

## Features
- News aggregation from RSS and APIs
- AI summarization
- Personalized ranking (topic preference, freshness, source quality, novelty)
- Search, filter, bookmarking
- Daily briefing

## Stack
- Frontend: React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- Backend: Python 3.12, FastAPI, SQLAlchemy, PostgreSQL
